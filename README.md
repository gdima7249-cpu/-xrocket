# Crypto trading bot (EMA + RSI)

Спотовый бот на `ccxt`: анализирует свечи, покупает при пересечении EMA снизу вверх
(если RSI не перегрет), продаёт по обратному пересечению, стоп-лоссу или тейк-профиту.

## Установка
    pip install -r requirements.txt
    cp .env.example .env     # заполнить

## Порядок использования
1. **Бэктест** на реальной истории (нужен доступ к бирже):
       python backtest.py --days 365
   Без интернета проверить код: `python backtest.py --synthetic`
2. **Paper** (`MODE=paper`): `python bot.py` — реальные цены, виртуальные $1000.
3. **Testnet** (`MODE=testnet`): ключи с testnet.binance.vision, ордера на песочнице.
4. **Live** (`MODE=live`) — только после недель стабильной работы на предыдущих этапах.
   Бот попросит подтверждение `YES`.

## xRocket
`EXCHANGE=xrocket` (по умолчанию): публичные данные xRocket Exchange API (свечи), режим **только paper**.
Ордера и баланс xRocket появятся после добавления документации Place order и Account balances.
Пара пишется как `BTC/USDT` (адаптер сам превращает её в `BTC-USDT`).
Не проверено на реальной сети: лимит свечей на запрос и точность количества.

## Настройки
Параметры стратегии и риска — `config.py` (класс `Params`): периоды EMA/RSI, стоп/тейк,
риск на сделку (1%), максимум позиции (50%), дневной лимит убытка (3%), комиссия.
Пара, таймфрейм, биржа, ключи, Telegram — `.env`.

## Реальные ордера на xRocket (спот)
    EXCHANGE=xrocket, MODE=testnet (бот @xrocket_testnet_bot) или live, MARKET=spot, API_KEY=<Bearer-токен>
Рыночные ордера (`type=market`, `size` в базовой монете, IOC) — как в официальном руководстве xRocket; исполнение
проверяется по истории ордеров. Цена — из `/api/v1/ticker/24h`. Токен можно задать переменной `XROCKET_TOKEN`
или `API_KEY` в `.env`. На testnet пары другие (в руководстве пример `TON-USDT`): `SYMBOL=TON/USDT`.
Торгуется **торговый** баланс (Trading), а не основной (Funding) — переведите средства в приложении.
Сначала `python check_exchange.py` (покажет мин. ордер и баланс, ордеров не шлёт), потом testnet.

## Проверка ордеров на тестовой среде
    python test_trade.py   # MODE=testnet/demo: покупает минимум и сразу продаёт обратно (нужно ввести YES)
Позволяет проверить цепочку ордеров, не дожидаясь сигнала стратегии. В режимах paper/live отказывается работать.

## Фьючерсы (long и short)
    MARKET=futures, SYMBOL=BTC/USDT:USDT (для paper на xRocket можно BTC/USDT), LEVERAGE=2
Пересечение EMA вверх -> long, вниз -> short. Изолированная маржа, плечо до 5, стоп/тейк на бирже,
общий стоп-кран. Бэктест: `python backtest.py --market futures --days 30`,
подбор: `python optimize.py --market futures --days 30`. Paper моделирует маржу, комиссии и ликвидацию.
Сумма должна покрывать минимальный ордер контракта (`python check_exchange.py` покажет его).

## Bybit
    EXCHANGE=bybit, MODE=demo (демо-ключи Bybit Demo Trading), SYMBOL=BTC/USDT
    python check_exchange.py   # безопасная проверка: рынки, мин. ордер, баланс (ордера не шлёт)
    python bot.py
Реальные деньги: MODE=live и боевой ключ только с правом торговли (без вывода).

## Сравнение стратегий
    python optimize.py --days 365 --timeframes 1h,4h --symbols BTC/USDT,ETH/USDT,GRAM/USDT
Стратегии (спот, только покупка): `ema_rsi` (базовая), `trend_pullback` (откат в тренде), `donchian` (пробой канала),
`bollinger` (возврат к среднему). Набор «проходит», если прибылен в каждом из 3 последовательных периодов.
В конце — **контроль**: доля проходящих наборов на реальных данных против перемешанных (случайных) и «устойчивые»
наборы (проходят минимум на 2 парах). Если на реальных данных проходит не больше, чем на случайных, стратегиям доверять нельзя.
Нужны `FEE=0.003` и `SLIPPAGE=0.0025` в `.env` (реальные издержки xRocket).

## Выбор стратегии
`STRATEGY=ema_rsi` (по умолчанию) или `STRATEGY=donchian` (пробой канала: вход при закрытии выше максимума за `DONCHIAN_IN`
свечей, выход при закрытии ниже минимума за `DONCHIAN_OUT`, стоп 3% / тейк 6%). Для donchian на 4-часовых свечах: `TIMEFRAME=4h`.

## Общий стоп-кран
`MAX_TOTAL_LOSS_PCT=0.20` в `.env`: когда капитал упадёт на 20% от стартового
(1000 -> 800), бот продаёт позицию и полностью останавливается; при перезапуске
остаётся остановленным, пока не удалить `state.json`. Можно задать абсолютный
порог `STOP_EQUITY` (в USDT). Проверка идёт каждые ~30 секунд, при резком гэпе цена
может проскочить порог, поэтому реальный убыток бывает чуть больше.

## Безопасность
- API-ключи **без права вывода средств**, по возможности с привязкой к IP.
- `.env` не коммитить (он в `.gitignore`).

## Важно
Это каркас, а не гарантия прибыли. Простые стратегии часто проигрывают Buy & Hold
после комиссий. Сначала смотрите бэктест на реальных данных и подбирайте параметры
на одном периоде, а проверяйте на другом (иначе переобучение). Торгуйте только
теми деньгами, которые готовы потерять.
